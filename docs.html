Quick Start

  1. Create a project with New Project, then drag objects from the palette.
  2. Drag objects from the palette onto the canvas, or use the + buttons.
  3. Select an object → set its properties on the right (size, color, text, rotation…).
  4. Add code: Explorer → object → + → Add Script (On create / Every frame / On click).
  5. Press ▶ Play — the Game tab runs your game live. Console tab shows log() output and errors.
  6. Everything autosaves to your browser (IndexedDB). Export gives a standalone HTML file.

Variables

Game memory: numbers, text, booleans. Counters/progress bars/sliders/toggles bind to them, texts show them with {{Name}}, and scripts read/write them. You never need to pre-create one: set("Coins", 5) creates Coins automatically.

Events (no-code)

Optional trigger chains: “on click → add to variable / set text / play sound / run a code snippet”. If you like coding, ignore events and use scripts — they do strictly more.

Script API — full reference

Available in every script, no imports needed. Scripts are async: await works.

Performance & safety notes

O(1) lookupsobj() uses an internal name index (rebuilt only on spawn/destroy/rename). For hot loops, cache the handle: local ball = obj("Ball") once, then ball.x += 10 * dt.
⚠️ ShadowingDo not name your own variables/functions after API commands (get, set, obj, wait, spawn…). Your declaration overwrites the engine command in that script scope — silent failure.
Dot notationEngine objects use direct dot access in both languages (self.x, obj("Ball").visible). Lua colon syntax (:) is not required — full JS parity.
Async waitwait() compiles to JS await: pauses only that script; the game loop keeps running.

Lua — same engine, easier language

Any script tab has a JavaScript / Lua dropdown. Lua is compiled to JS at Play time by js/runtime/luac.js (~200 readable lines — no 600 KB interpreter dependency, works in the standalone export too).

-- On click on "Mine"
local cost = math.ceil(get("Per click") * 25)
if get("Coins") < cost then
  beep(160, 90)
  return
end
subtract("Coins", cost)
multiply("Per click", 2)
setText("Upgrade", "Pickaxe x" .. get("Per click"))
LuaMeans
local x = 5 · nil · truevariables, no value, booleans
{1,2,3} · {hp = 10}array tables · hash tables (dicts)
if/elseif/else · while · repeat…untilconditions & loops
for i = 1, 10 do · for v in ipairs(t) · for k, v in pairs(t)all for-forms
function f(a) return a * 2 endfunctions
a .. b · #t · ~= · and/or/notconcat, length, compare, logic
math.ceil/floor/abs/sqrt/min/max · table.insert/removestandard library bits
pcall(f) · error("msg") · warn(x) · print(x)error handling & debug — e.g. local ok, err = pcall(function() set("Coins", "x") end); if not ok then log("Script Error: " .. err) end
wait(1)blocks the script only — game keeps running

Not supported (honest): metatables, coroutines, goto, colon method calls, multi-return, varargs, string.format/gsub/gmatch, tonumber/tostring. Fixed 2026-11: math.random(a,b) now compiles correctly (was returning 0–1!), and table.insert(t, i, v) / table.remove(t, i) positional forms work. a .. b compiles to + — fine for text, but 1 .. 2 gives 3, not "12". Full list: docs/lua.md. Switch any script tab to Lua — the whole API works.

self, dt & time

// On update script on a shape called "Ship"
self.x += 200 * dt;              // dt = seconds since last frame (~0.016)
self.rotation = time * 45;      // time = seconds since Play
if (self.x > 960) hide(self.name);
self.visible = !self.visible;    // blink it

self = the object owning the script (in Game scripts it's a shared "brain" object — store your own state on it: self._next = time + 2;). You can read/write x, y, w, h, text, visible, opacity, rotation, bg, color, seconds and anything else you invent.

Game Loop

Every frame (~60×/s): timers tick → On update (game script) → every object's Every frame scripts → changed objects re-render. On create runs once when Play starts. On click runs on real clicks in the Game tab.

Keyboard

// in any update script
if (key("arrowleft") || key("a")) self.x -= 300 * dt;   // held down
if (pressed("space")) add("Jumps", 1);                    // just this frame

Names are lowercase: "a"…"z", "0"…"9", "space", "enter", "escape", "arrowup", "arrowdown", "arrowleft", "arrowright", "shift", "control". Keys typed while editing code don't reach the game.

Ideas to build

The engine ships no premade games — you build everything. Popular first projects: clicker (variables + upgrade costs), reaction test (time + beep()), catch-the-shape (moveTo + countdown), keyboard dodge (pressed() + spawn/destroy), quiz (data arrays), breakout (touching() + bounce), platformer (cam.follow + gravity), two-room adventure (Trigger + gotoScene()). Every API in this guide exists so you can build them with pure code.
